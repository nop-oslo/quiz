# IPSC Rules Quiz

Independent English-language practice for nine IPSC disciplines. Each discipline has 216 question cards drawn in 18 rounds of 12, with four options and one correct answer per card. The bank includes separate rule questions and parameterized scenarios. Variants in the same question family are distributed across different rounds. A new cycle begins after all 216 cards have been drawn, with no question carried over from the final round of the previous cycle. Check each answer to lock it in and reveal the correct answer and rule before continuing. The final result shows correct answers, incorrect answers and the percentage. The answer review links to the rule book or relevant interpretation.

The quiz runs in the browser without an account, analytics, server or external runtime dependencies. Scores and answers are held in memory. Only the shuffled question IDs are kept in browser storage, separately for each discipline. A round counts as drawn when it is started. If storage is blocked, repeat prevention lasts for the current page session. Use **Save result image** to create a PNG that can be uploaded to Facebook. Browsers that support file sharing can also offer the native share menu.

## Run locally

Open `index.html` in a browser, or serve this directory using a static HTTP server.

## Publish on GitHub Pages

Put these files in the root of a GitHub repository. In **Settings → Pages**, select **Deploy from a branch**, then select **main** and **/ (root)**. The repository owner's Pages settings determine which audiences can access the site.

## Rules and maintenance

The question bank is in `questions.js`. Each quiz cites the relevant January 2026 rule book. The Shotgun bipod question references the May 2026 interpretation. The forced reset trigger question references the February 2026 interpretation. Common questions appear across disciplines where the cited provisions match. The rules index also includes combined competition formats and Grand Tournament, which are outside the discipline quizzes.

[Official IPSC rule books and interpretations](https://www.ipsc.org/ipsc-rules/rule-books/)
